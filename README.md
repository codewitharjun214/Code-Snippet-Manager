# 📝 Code Snippet Manager

The **Code Snippet Manager** is a full-stack application that allows developers to **save, organize, and search** their favorite code snippets.  
With features like **syntax highlighting, tagging, and dark mode**, it’s a perfect tool for productivity.

---

## ✨ Features
- 🔐 **User Authentication** (JWT)  
- 📝 **Add Snippets** with code editor (Monaco/Prism.js)  
- 🏷️ **Tags & Categories** for organization  
- 🔍 **Search & Filter** snippets by language/tags  
- 🌙 **Dark Mode** with Tailwind CSS  
- 📱 **Responsive UI**  

---

## 🛠️ Tech Stack
- **Frontend**: React, TypeScript, Tailwind CSS  
- **Backend**: Node.js, Express.js  
- **Database**: MongoDB  
- **Authentication**: JWT
